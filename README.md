# Molecular Solubility Prediction using Machine Learning

A beginner Machine Learning project built with Python and scikit-learn to predict molecular solubility (logS values) using regression analysis.

The project demonstrates the complete supervised learning workflow, including data preprocessing, train/test splitting, model training, prediction, evaluation, and visualization.

##  Key Features
- Loaded and analyzed molecular data
- Applied train/test split for model evaluation
- Trained a Linear Regression model
- Generated predictions on unseen molecular samples
- Evaluated model performance using R² score
- Visualized actual vs predicted values using Matplotlib

##  Concepts Practiced
- Supervised Machine Learning
- Linear Regression
- Train/Test Split
- Model Evaluation
- Data Visualization
- Working with scientific datasets

##  How It Works
The model learns relationships between molecular features and solubility values using historical data.

After training, the model predicts solubility values for unseen molecules and compares predictions against real values to evaluate performance.

##  Tech Stack
- Python 3
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
